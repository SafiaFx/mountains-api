# Original coursework reference files

These files are retained from the completed CS253 Web Service Development coursework:

- `MountainConnector.java`: the standalone, package-free client prepared for the original autograder.
- `inlinebrackets.xml` and `separatebrackets.xml`: supplied style configuration files.

They are reference material and are not part of the Maven build. The maintained application client is `src/main/java/org/example/mountains/MountainConnector.java`. The first repository commit preserves the imported coursework before the portfolio improvements.

The supplied `DemoTests`, `SharedResources` and `Response` helpers remain in the main source package for compatibility. Their original course comments are preserved; new automated tests supplement the demonstration checks.
